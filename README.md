# Nanterre Pirates - Rugby League Automation Suite 🏴‍☠️

A collection of Rust-based tools designed to automate notifications and data tracking for our club's Discord server.

## Features

*   **Live Match Monitor:** A web scraper that monitors Rugbyrama's live page for Super League games and sends Discord alerts.
*   **RSS Feed Notifier:** Monitors the *Treize Mondial* RSS feed and notifies the Discord server whenever a new article is published.
*   **League Standings Tracker:** Automatically fetches and updates current NRL standings for our community to follow.
*   **Super League Tracker:** Scrapes Sky Sports for the latest Super League results and live standings updates.
*   **Super XIII Tracker & YouTube Monitor:** Monitors the French Super XIII championship on FFR13 (adaptive polling, match results, standings updates) and scans the YouTube channels of all 11 clubs from Monday to Friday for home match broadcasts.

## Tech Stack
*   **Language:** Rust
*   **Platform:** VPS (Linux) / Windows
*   **Notification:** Discord Webhooks
